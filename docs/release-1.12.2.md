# Release 1.12.2

## Web UI and docs status

- Текущий web UI уже ушел дальше скриншотов 1.0: появились вложения `📎`, переключатель стриминга, кнопка `Стоп`, memory strategies и отдельный блок `Контекст` в метриках.
- How-to и product docs обновлены под актуальные routes `/api/agent/*` и `/api/chat*`, текущую схему metrics (`request`, `context`, `session`) и хранение в TOON.
- PNG-скриншоты в `docs/assets/` помечены как исторические: они больше не отражают весь набор controls и должны быть пересняты на машине, где локальный браузер не заблокирован политикой среды.
